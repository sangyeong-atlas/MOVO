# 구현 범위와 기획의 구분

기획서는 장기 목표를 포함합니다. 이 문서는 제출 소스의 현재 상태를 설명합니다.

| 기능 | 현재 상태 |
|---|---|
| 계정·파티·초대·픽업·좌석·공동 코스 | 공통 API와 영속 저장 구현 |
| SSE·폴링·재연결·승인·요청 ACK | 구현; 백엔드 회귀 테스트 포함 |
| 카카오 장소 검색·네이버 도로 경로 | 실제 제공자 연동 구현; 본인 키와 네트워크 필요 |
| 모바일/차량 MOVO 지도 경로 공유 | 같은 서버 snapshot의 polyline 사용 |
| Pleos NaviHelper | SDK 연동, 운전자 확인 후 목적지/경유지 전달과 결과 판정 구현 |
| STT·TTS·빠른 메시지 읽기 | Pleos ON_DEVICE 한국어 SDK 연동 |
| Hey MOVO | 선택적 STT 기반 foreground service; Gleo/하드웨어 hotword 아님 |
| 차량 이동·공조 | 시뮬레이션; 실제 차량 제어 아님 |
| GPS·센서 결합 자동 탑승 | 미구현; 현재 수동 확인 |
| FusedLocation·Vehicle SDK·Gleo | 향후 연동 범위 |
| 연속 주행 감지·휴식 추천 | 향후 개발 범위 |
| 주차 저장·확인·여정 기록 | 구현; 실차 시동/주차 신호 자동 감지 미연동 |
| 상용 인증·푸시·사전 탑재 | 미구현/미확정 |

도로 경로는 현재 조회 시점 교통에 따른 추정입니다. 경유지 추가 이동시간은 주행시간 차이이며 체류시간을 포함하지 않습니다. Pleos 기본 내비 경로와 네이버 경로가 같다고 보장하지 않습니다. 외부 API 실패·권한 미지원·오래된 상태는 안내하고, 요청 승인만으로 적용 성공을 확정하지 않습니다.

공개 서비스 운영을 위한 인증·배포 인프라가 완성된 제품은 아닙니다. 본 제출물은 정차 상태의 에뮬레이터에서 합성 계정과 테스트 여정으로 시연합니다.
